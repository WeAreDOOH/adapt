# Adapt

Adapt is a client-demo creative versioning studio for turning delivery spreadsheets and one prepared layered source into a coherent family of DOOH layouts. It demonstrates AI-assisted size extraction and layout analysis, a Ratios-style minimal delivery footprint, real PSD layer parsing, responsive artboards, background bleed and focal positioning, shared copy and intelligent type fitting, logo anchoring, layout guides, scope-aware overrides, and deliberate refinement of similar aspect ratios.

The format catalogue uses the supplied Deliver export unchanged: 1,503 production specifications from 121 media owners, covering 549 unique pixel dimensions and 320 exact aspect ratios. At the default 8% float and 6% crop allowances, it reduces to 38 editable PSD masters. The tolerances remain live and visible rather than hiding production compromises.

## Demo journey

1. Start from the intentionally empty interface and upload `.xlsx`, `.xls` or `.csv`, or choose the supplied Deliver catalogue.
2. Review detected dimensions. Separate width/height columns and combined values such as `1080 × 1920` are supported. Physical `mm`, `cm`, `m`, `in` and `ft` sizes use the selected 300–500 DPI and artwork scale.
3. Adjust float/crop tolerances and review the proposed exact-downscale, float and crop groupings.
4. Download the full layered PSD template pack, or use `public/demo/brighter-after-dark-prepared.psd`.
5. Upload the prepared PSD, review its real layer tree, and run structured OpenAI layout analysis before entering the responsive artboard studio.

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:4173`. The local server loads `.env.local`, keeps the API key server-side and serves the Vite app. Copy `.env.example` to `.env.local` and add `OPENAI_API_KEY` to enable the two AI checks; without it, every stage remains usable with the explicitly labelled deterministic rules engine.

Run the complete local check with:

```bash
npm run check
```

## PSD support and demo fallback

- **Real PSD support:** the browser-side `ag-psd` adapter reads a selected `.psd`, walks its layer tree, imports editable text and source geometry, and maps layer names to semantic roles. The PSD binary remains local. When the user requests AI layout analysis, only layer names, kinds, geometry and requested master sizes are sent to the server-side OpenAI call.
- **Prepared sample:** `Brighter After Dark` is a genuine 2400 × 1600 layered PSD generated by `scripts/generate-demo-psd.mjs`. It contains eight editable semantic layers, Photoshop guides and an explicit background smart-object/AI-extension target. This is clearly labelled as prepared demo artwork, not a customer PSD.
- **Fallback:** if OpenAI is unavailable, deterministic column inference, semantic layer rules and family overrides complete the journey. The UI labels that result as the deterministic fallback.
- The current importer deliberately skips PSD pixel data in the responsive renderer; the artboards visualize the DCO semantics rather than claiming Photoshop-perfect compositing.

## Architecture

- `src/core/schema.ts` — `dooh.adapt-template` v1 schema, cascade resolution, ratio similarity and smart type fitting.
- `src/core/ratioPlanner.ts` — fidelity-first master grouping using exact downscale, float and crop tolerances.
- `src/core/psdExport.ts` — browser-side layered PSD template-pack generation.
- `src/importers/` — modular adapters. PSD is available; After Effects, InDesign and Figma are explicit planned seams.
- `src/importers/spreadsheet.ts` — Excel/CSV parsing, flexible dimension discovery and physical-size conversion.
- `src/components/Artboard.tsx` — deterministic responsive preview shared by every format.
- `src/core/sample.ts` — client-safe style system used to enrich parsed layer semantics.
- `server.mjs` — local server and structured OpenAI spreadsheet/layout analysis endpoints.
- `public/data/deliver_unique_format_sizes.csv` — unchanged Deliver format source supplied on 24 November 2026.

The cascade resolves `Global → family → local`, preserving deliberate exceptions while shared edits keep flowing. Export produces a portable versioned JSON DCO template.

## Reference decisions

- Ratios inspired fidelity-first geometry, shared placement rules and visible verification.
- Rush Studio inspired the inheritance cascade, artboard workspace and scoped editing.
- UGC Studio inspired versioned contracts and independent adapter boundaries.
- Plume inspired local-first operation, strong presets and graceful capability fallback.

No reference studio was merged wholesale.
